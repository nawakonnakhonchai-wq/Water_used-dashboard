# Dashboard การใช้น้ำในพื้นที่นิคมอุตสาหกรรม / ท่าเรือฯ

หน้าเว็บสรุปการใช้น้ำ น้ำ 3R น้ำสำรอง และระบบบำบัดน้ำเสียรายนิคม จาก Google Sheets “0 ไฟล์รวมน้ำ 64-ปจบ” (ชีต1 แถว 1–74)

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้า Dashboard ทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว ใช้ d3 จาก cdnjs) |
| `data.json` | ข้อมูลชีต1 ช่วง `A1:TX74` ที่หน้าเว็บโหลดตอนเปิด |
| `regions.json` | การจัดนิคมเข้าจังหวัดและกลุ่มพื้นที่ (EEC, กรุงเทพฯ–ปริมณฑล, ภาคกลาง, ภูมิภาคอื่น) ทำจากชื่อนิคม ไม่ได้มาจากชีต |
| `.nojekyll` | ให้ GitHub Pages ส่งไฟล์ตามเดิมโดยไม่ผ่าน Jekyll |

## ข้อมูลอัปเดตอย่างไร

- เปิดหน้าเว็บ: แสดงข้อมูลจาก `data.json` (เวลาที่บันทึกแสดงบนหัวหน้าเว็บ)
- กดปุ่ม **อัปเดตข้อมูล**: ดึงค่าล่าสุดจากชีตโดยตรง แสดงเฉพาะในเบราว์เซอร์ของคนที่กด ไม่ได้แก้ไฟล์ใน repo และไม่ได้แก้อะไรในชีต
  - ปุ่มนี้ใช้ได้เมื่อชีตตั้งแชร์เป็น **ทุกคนที่มีลิงก์ → ผู้มีสิทธิ์อ่าน** ถ้ายังไม่ได้ตั้ง หน้าเว็บจะแจ้งเตือนและแสดงข้อมูลเดิมต่อ
- อัปเดต `data.json` ให้ทุกคนเห็นข้อมูลใหม่: แทนที่ไฟล์ด้วยค่าชีต1 `A1:TX74` ชุดใหม่ (รูปแบบ `{"updated": "<เวลา ISO>", "values": [[...แถวละรายการ...]]}`)
